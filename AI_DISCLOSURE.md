# AI assistance disclosure

Microsoft Copilot was used during this project for:

- Refining the product concept and user journeys
- Translating the supplied barebone HTML into a Next.js architecture
- Generating and reviewing TypeScript, React, Tailwind CSS and API-route code
- Creating synthetic demonstration content
- Drafting architecture, security, responsible-AI and pitch documentation
- Preparing test, deployment and submission checklists

Copilot Studio is represented as an optional target agent runtime. It was not connected to production data or a production tenant in the packaged demo. The default bot behavior is deterministic retrieval over synthetic content.

All AI-generated output remains subject to human review. No real or confidential business data was supplied to the demo application or intentionally embedded in this repository. The final submission owner is responsible for validating source code, licenses, security, accessibility and compliance before publication or production use.
