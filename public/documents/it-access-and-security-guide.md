# IT Access & Security Guide

**Document status:** Active sample policy  
**Version:** 1.5  
**Effective date:** 10 March 2026  
**Owner:** Technology Support

## Access requests

Request application access through the service portal. Include the business reason, required role, manager approval, and end date for temporary access.

## Password and multifactor authentication

Use a unique work password and complete multifactor authentication prompts only when you initiated the sign-in. Never approve an unexpected prompt.

## Reporting an incident

Report suspected phishing, lost devices, unexpected multifactor prompts, or possible data exposure immediately through the security incident option in the service portal.

## Data handling

Store work information only in approved Microsoft 365 locations. Do not forward work files to personal accounts or upload them to unapproved services.
